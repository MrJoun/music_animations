# Alignment evidence plots

Each plot overlays **forced-aligned word onsets** (red vertical lines) on the
**Demucs-separated vocal energy** (blue) for a window of the song. Onsets landing on the
vocal energy rises = lyric words highlighting in time with the singer.

Generated with:

```bash
python tools/plot_alignment.py "<Song>.analysis/stems/vocals.wav" \
       "<Song>.analysis/word_schedule.json" --start <t0> --end <t1> --out out.png
```

| File | Track | Lyrics source | Window |
|------|-------|---------------|--------|
| `yebba_far_away.png` | YEBBA — Far Away | `yebba_far_away_lyrics.txt` | 0–22 s (verse + chorus) |
| `hozier_too_sweet.png` | Hozier — Too Sweet | LRCLIB auto-fetch | 19–37 s |
| `justin_bieber_daisies.png` | Justin Bieber — DAISIES | LRCLIB auto-fetch | 18–36 s |
| `charli_xcx_party_4_u.png` | Charli XCX — party 4 u | LRCLIB auto-fetch | 24–42 s |

These are checked in as documentation; the underlying `*.analysis/` packs are gitignored
and regenerated by `tools/analyze_song.py`.
